Quickstart

Start locally with Node.js 20.6 or Docker. Live public feeds work without API credentials; paid data stays locked until B402 is configured. The dashboard demo is browser-local and uses labeled sample fixtures; it does not authorize API or MCP requests.

cp .env.example .env
npm start
# open http://localhost:8787

Resolve and last price are free. Paid HTTP and MCP calls return 402 until a wallet signs B402 payment terms; there is no simulated-payment header.

curl 'http://localhost:8787/api/v1/resolve?symbol=NVDA'
# Paid state requests require an x402/B402 wallet authorization; see the payment flow below.

B402 / x402 payment flow

Paid routes use x402 v2 on BNB Smart Chain (eip155:56). A 402 returns payment terms in the PAYMENT-REQUIRED header. The connected BNB wallet reviews and signs a scoped B402 EIP-3009 authorization; PulseLayer retries with PAYMENT-SIGNATURE and returns data only after settlement. The settlement result is returned in PAYMENT-RESPONSE. Paid data is returned only after confirmed settlement. Successful B402 settlements only are written to the Agent log. The browser dashboard demo is local sample data and creates no receipt.

{ "error": "payment_required", "payment": {
  "protocol": "x402", "network": "eip155:56",
  "amountUsd": "0.02", "resource": "/api/v1/state",
  "facilitator": "not_configured"
}}

Production settlement uses the BNB-maintained B402 server adapter and x402 Express payment middleware. It remains disabled until B402 merchant credentials, a payout wallet, a token contract, and an atomic amount are configured. Startup fails closed when these settings are incomplete. No demo header or simulated settlement can authorize a paid request.

MCP server

Connect an MCP client to the JSON-RPC endpoint at /mcp. It implements initialize, tools/list, and tools/call.

Tools: resolve_asset, last_price (free), quote_pack, eligibility_pack, market_state, compare_issuers, signal_call, agent_calls, historical_state, bstocks_news (paid). Paid tools require wallet-signed B402 settlement; there is no demo bypass.

{ "mcpServers": { "pulselayer": {
  "url": "http://localhost:8787/mcp"
}}}

Discovery card: /.well-known/agent.json.

JavaScript SDK

Zero-dependency SDK example:

import { PulseLayer } from './examples/client.js';
const pulse = new PulseLayer('http://localhost:8787');
const asset = await pulse.resolve('NVDA');
const price = await pulse.lastPrice('NVDA');
// Paid methods accept a walletSigner callback. It receives the 402 challenge

Data quality & estimates

Live adapters combine Binance BNB RWA issuer records and status, Yahoo Finance underlying references, the xStocks public quote and trading feed, DexScreener BNB pools, and PancakeSwap route quotes. If a required upstream feed fails, responses identify deterministic fallback data with source: seed-demo. Contract addresses come from the live Binance issuer catalog; catalog listing does not claim independent on-chain verification.

  • Weekend / after-hours gap compares issuer token prices with the latest completed underlying session close, and is blank during regular hours.
  • Thin print: fewer than 8 daily pool trades or less than $15,000 reported pool depth.
  • Executable size and slippage require a live PancakeSwap exact-input route quote at sampled order sizes; unavailable quotes remain unknown.
  • Best venue uses measured route impact when available, otherwise reports pool-liquidity ranking only.
  • Confidence combines coverage, event status, observed pool data, freshness, and thin-print penalties.

Signal calls combine reference premium/discount, closed-market gap direction, recent issuer-specific headlines, halt events, liquidity, tradeability, and event-coverage confidence. Headline keywords are transparent heuristics, not a valuation model. Headlines older than 72 hours or lacking a valid timestamp do not affect the score. Deterministic scoring remains the baseline. When configured, Qwen or OpenAI can review only the supplied evidence and return BUY, SELL, or HOLD with a horizon; the recorded call retains its baseline, cited evidence IDs, model identity, and fallback state. Set LLM_PROVIDER, LLM_MODEL, LLM_API_KEY (or provider key), and optional LLM_BASE_URL. Use the model provider’s regional endpoint for Qwen. The bStocks news endpoint returns each catalog-listed underlying, matching recent headlines, bullish/bearish/neutral sentiment, and explicit no-coverage states. Sentiment uses transparent title-keyword heuristics and a 72-hour freshness window; it is not a recommendation. News uses configurable RSS headline metadata, not article-text licensing or a real-time guarantee. The sample news shown in demo mode is explicitly labeled as such.

Issuer status is adapter supplied; incomplete event coverage stays unknown. Session status comes from the reference feed trading-period schedule. Market snapshots and Agent Calls append to durable JSONL storage. B402 replay protection is file-backed for one service process; multi-replica deployments need shared atomic storage.

PulseLayer does not execute trades. Buy/Sell/Hold calls are time-stamped decision-support outputs with an explicit review horizon, not guarantees or personalized financial advice.
